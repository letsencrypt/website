Let's Encrypt выпускает сертификаты через автоматизированный API на основе [протокола ACME](https://en.wikipedia.org/wiki/Automatic_Certificate_Management_Environment).

Для взаимодействия с API Let's Encrypt и получения сертификата требуется программное обеспечение, называемое «ACME-клиентом». Никакая часть процесса получения сертификата не осуществляется на этом сайте; он носит исключительно информационный характер.

Первый вопрос, на который нужно ответить тем, кто хочет начать работу с Let's Encrypt: будет ли мой хостинг-провайдер получать и управлять сертификатами Let's Encrypt для меня, или мне нужно будет запустить ACME-клиент самостоятельно?

# Получение сертификатов через вашего хостинг-провайдера

Для большинства людей, сам [хостинг-провайдер получает сертификаты от Let's Encrypt и управляет ими](https://certbot.eff.org/hosting_providers). Если это ваш случай, значит, ваш провайдер использует ACME-клиент, и вам не нужно задумываться о том, чтобы самостоятельно использовать программное обеспечение ACME-клиента.

Если ваш провайдер получает сертификаты и управляет ими за вас, это будет происходить либо автоматически, либо потребуется включить соответствующую настройку. Ознакомьтесь с документацией и параметрами конфигурации вашего провайдера.

# Выбор и использование ACME-клиента

Если ваш хостинг-провайдер не берет на себя получение и управление сертификатами, а у вас есть возможность выполнять команды на сервере с достаточными правами доступа, вы можете выбрать ACME-клиент и самостоятельно использовать его для получения сертификатов от Let's Encrypt.

Для большинства людей мы рекомендуем [Certbot ACME клиент](https://certbot.eff.org/). На веб-сайте Certbot представлена ​​отличная документация и инструкции по работе с Certbot.

Существует [множество других вариантов ACME-клиентов](/docs/client-options/), если по какой-то причине Certbot вам не подходит.

Если для вашего клиента требуется настроить точку входа в сервис через API ACME-клиента от Let's Encrypt, то она выглядит так:

<code>[https://acme-v02.api.letsencrypt.org/directory](https://acme-v02.api.letsencrypt.org/directory)</code>

Мы рекомендуем сначала запустить тесты с использованием нашей [промежуточной среды API](/docs/staging-environment/).
