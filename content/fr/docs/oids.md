Un identifiant d’objet (OID) est une séquence de nombres séparés par des points utilisée pour identifier de manière unique différents objets dans le WebPKI. Par exemple, chaque extension dans d'un certificat X.509 est uniquement identifiée par un OID, et l'OID `2.5.29.15` identifie l'extension [Key Usage](https://datatracker.ietf.org/doc/html/rfc5280#section-4.2.1.3). De même, l'OID `2.23.140.1.2.1` peut être placé dans le corps de l'extension [Certificate Policies](https://datatracker.ietf.org/doc/html/rfc5280#section-4.2.1.4) pour indiquer que le certificat a été validé selon les [critères de AC/Forum de Navigateur "Domaine Validé"](https://github.com/cabforum/servercert/blob/main/docs/BR.md#12-document-name-and-identification).

Cette page liste les OID utilisés par Let's Encrypt, documente ce que chaque OID signifie et pointe vers l'endroit où nous les utilisons.
